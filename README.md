# 物理認証とワンタイムパスワードによる２段階認証の出席システム
## nfc等物理認証とpyotpによるワンタイムパスワードによる２段階認証で構成された偽装しにくい出席システムの作成
### 各ファイル説明
#### app.py 
ユーザー追加システムを主としたサーバー側メインプログラム.
#### main.py
tagを読み取り(2026/04/14時点では,inputによる変数の取得で代用),ユーザーからワンタイムパスワードを受け付けデータベースからtag_idから検索したシークレットキーとユーザーのパスワードの整合するプログラム. 
#### load_json.py
oauth用の鍵等のjsonとmysqlのjsonを二つ読み取るためのプログラム.<br>
main.pyとapp.pyで使用
#### oauth.json
Google Oauth用のトークン及び秘密鍵用のjson.
#### pass.json
My SQL用のjson
#### sql
##### schema.sql
データーベース作成用
##### seed.sql
データ挿入フォーマット
